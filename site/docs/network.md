# 网络设置

**设置 → 系统 → 网络**

网络设置用于统一管理工作流的外部访问行为，适合部署在 NAS、Docker 或受限网络环境中的实例。配置完成后，工作流中的 HTTP 请求节点可自动复用这些网络参数。

## 全局代理

- 为工作流 HTTP 请求节点设置全局代理
- 支持 HTTP、HTTPS、SOCKS5 等常见代理类型
- 适用于访问受地区、运营商或网络出口限制影响的站点

## 连接验证

- 修改配置后可通过实际工作流请求验证连通性
- 统一代理设置可减少逐个节点重复填写网络参数的成本

## 典型用途

- 通过代理访问海外元数据源或索引站点
- 在公司、校园或家庭旁路网络环境中稳定执行自动化工作流
- 为整套搜索与刮削流程提供一致的网络出口策略
