# 下载管理

Kaloscope 通过适配器对接外部下载器，支持手动添加任务和基于关键词的自动下载计划。

## 支持的下载器

| 下载器 | 接口方式 | 默认地址 |
| --- | --- | --- |
| [aria2](https://aria2.github.io/) | JSON-RPC | `http://127.0.0.1:6800/jsonrpc` |
| [qBittorrent](https://www.qbittorrent.org/) | WebUI API | `http://127.0.0.1:8080/api/v2` |
| [Transmission](https://transmissionbt.com/) | RPC | `http://127.0.0.1:9091/transmission/rpc` |

下载器适配器通过 YAML 配置文件定义，位于后端 `static/downloaders` 目录，理论上可以扩展支持更多下载客户端。

## 配置下载器

首次使用前，需要在**设置 → 下载器**中添加并连接下载器：

1. 选择下载器类型（aria2 / qBittorrent / Transmission）
2. 填写连接地址、端口及认证信息
3. 点击「测试连接」验证是否可用
4. 保存后设为默认下载器

> 使用 Docker 部署时，如果下载器运行在宿主机上，地址填写 `http://host.docker.internal:<端口>` 而不是 `localhost`。如果下载器也在同一 Compose 中，直接使用服务名即可。

## 手动添加任务

在**下载**页面，可以通过以下方式手动添加任务：

- **磁力链接**：粘贴 `magnet:?xt=...` 格式的链接
- **种子文件**：上传 `.torrent` 文件

添加时可以指定保存目录，默认使用下载器配置中的默认路径。

## 下载计划

下载计划实现「自动追更」功能，无需手动搜索：

1. 在**下载 → 下载计划**中新建计划
2. 绑定一个索引器和下载计划工作流
3. 设置搜索关键词和过滤规则（如正则表达式过滤标题）
4. 配置执行间隔或 Cron 表达式

计划触发时，系统自动执行对应工作流搜索资源，对结果按过滤规则筛选，将符合条件的新资源提交到下载器。已下载的资源通过 info hash 去重，不会重复添加。

## 任务列表

下载页面实时展示所有进行中和已完成的任务，包括：

- 任务名称与大小
- 下载速度与进度
- 状态（下载中 / 暂停 / 完成 / 错误）
- 保存路径

支持对任务进行暂停、继续、删除等操作。
