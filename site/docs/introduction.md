# 项目简介

Kaloscope 是结合 **AI 助手**与**可视化工作流**的本地媒体库管理工具，串联资源搜索、下载、元数据刮削、入库与在线播放、阅读。资源搜索、元数据刮削等逻辑通过可编辑的工作流实现，可用自然语言生成和修改，也可直接编辑节点。

## 功能概览

- [AI 助手](./ai/assistant)：结合当前页面和日志查询状态、编写工作流、校验与试运行，在确认后管理下载、调度和影视入库
- [AI 工作流节点](./workflows/ai)：统一配置[云端或本地模型](./ai/)，在流程中生成文本或经过 Schema 校验的 JSON
- [MCP 接入](./ai/mcp)：使用独立访问令牌连接外部 AI 客户端，查询资源、编辑草稿和管理任务
- [可视化工作流](./workflows/)：编排 HTTP 请求、脚本、条件和循环，支持本地变量缓存与定时调度
- [多索引器资源搜索](./websearch/)：聚合搜索、在线预览、认证与收藏
- [下载管理](./downloads/)：连接 aria2、qBittorrent、Transmission、OpenList 或 NAS 迅雷，支持自动追更与完成后转移
- [媒体库管理](./medialibs/)：电影、电视剧、小说和漫画的扫描、实时监控、元数据刮削与[自动整理](./medialibs/organization)
- [在线阅读](./medialibs/reading)：支持 TXT、EPUB、图片目录与 CBZ/ZIP 漫画，保存阅读进度并继续阅读
- 在线播放：字幕、章节、续播、[弹幕匹配与过滤](./medialibs/danmaku)，以及[服务端转码](./medialibs/transcode)
- [网络设置](./network)：自定义 HTTP 代理与 DNS 解析规则
- [多用户与访问权限](./users)、[PWA 安装](./pwa)与国际化界面
- 系统监控：查看实时日志和管理转码任务

## 适用场景

- NAS 或家庭媒体服务器
- 自动搜索、下载、整理番剧资源
- 接入私有站点或定制刮削逻辑
- 管理本地小说和漫画，跨设备继续阅读
- 通过自然语言搭建流程，或从外部 AI 客户端管理媒体任务
