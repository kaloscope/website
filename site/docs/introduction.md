# 项目简介

Kaloscope 是一个运行在本地服务器上的媒体库管理工具，将资源搜索、下载、刮削入库与在线看片、阅读整合在一起。其中的搜索与刮削逻辑都用可视化工作流实现——你可以直接在画布上调整节点，也可以用自然语言让 AI 助手帮你生成和修改。

## 功能概览

- [AI 助手](./ai/assistant)：了解你当前打开的页面和应用日志，能帮你查状态、写工作流、试运行，也能在确认后操作下载、定时任务和影视入库
- [AI 工作流节点](./workflows/ai)：在[模型提供商](./ai/)中统一配置云端或本地模型后，就能在流程里生成文本或符合 Schema 的结构化 JSON
- [MCP 接入](./ai/mcp)：通过独立访问令牌对接外部 AI 客户端，直接查资源、改草稿或管理任务
- [可视化工作流](./workflows/)：把 HTTP 请求、脚本、条件和循环串成流程，支持本地缓存变量与定时调度
- [多索引器资源搜索](./websearch/)：聚合搜索多个站点、查看详情与在线预览，支持站点登录和收藏
- [下载管理](./downloads/)：接入 aria2、qBittorrent、Transmission、OpenList 或 NAS 迅雷，支持自动追更和下载完成后转移入库
- [媒体库管理](./medialibs/)：管理电影、电视剧、小说和漫画，支持自动扫描、实时监控、元数据刮削与[按模板整理文件](./medialibs/organization)
- [在线阅读](./medialibs/reading)：支持 TXT、EPUB、图片目录与 CBZ/ZIP 漫画，自动记录进度，跨设备接着读
- 在线播放：支持外挂与内嵌字幕、章节跳转、续播、[弹幕匹配与过滤](./medialibs/danmaku)，浏览器不支持直连播放时还可开启[服务端转码](./medialibs/transcode)
- [网络设置](./network)：按 URL 规则自定义 HTTP/SOCKS5 代理和加密 DNS 解析
- [多用户与访问权限](./users)、[PWA 安装](./pwa)及多语言界面
- 系统监控：实时查看系统日志，随时查看或清理转码任务

## 适用场景

- 在 NAS 或家庭服务器上自建私人媒体库
- 自动追更，按规则搜索、下载并整理番剧或剧集
- 接入私有站点或小众资源站，自己定制刮削规则
- 集中存放本地小说和漫画，在手机、平板和电脑上接续阅读
- 懒得手动拖拽节点时，直接对话搭建流程，或从外部 AI 客户端遥控媒体任务

## 注意事项

本项目仅供个人学习与技术交流。由于社区或第三方工作流里可能包含自定义脚本与网络请求，导入前请先自行确认其安全性与合法性。
