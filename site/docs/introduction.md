# 项目简介

Kaloscope 是以可视化工作流为核心的本地媒体库管理工具。资源搜索、元数据刮削、下载计划等逻辑通过可编辑工作流实现，而非硬编码到程序内部。

## 功能概览

- 可视化工作流编辑器
- 多索引器资源搜索
- 媒体文件扫描与 NFO 元数据解析
- 支持 aria2、qBittorrent、Transmission
- 内置播放器（FLV、HLS、MP4）
- 多用户与权限控制
- PWA 安装与国际化界面

## 适用场景

- NAS 或家庭媒体服务器
- 自动搜索、下载、整理番剧资源
- 接入私有站点或定制刮削逻辑

## 注意事项

本项目仅供个人学习与技术交流使用。社区或第三方工作流可能包含任意代码或网络请求，使用前应自行审查其安全性与合法性。
