# PWA 安装

Kaloscope 支持以 PWA（Progressive Web App）方式安装到桌面或移动设备，在保留 Web 部署灵活性的同时，提供更接近原生应用的使用体验。

## 可安装方式

- 在桌面浏览器中安装到系统应用列表或任务栏
- 在手机或平板浏览器中添加到主屏幕
- 安装后可直接从图标启动，无需每次手动输入地址

## 使用体验

- 应用拥有独立窗口与图标，适合长期常驻使用
- 支持自动生成多尺寸图标，兼容不同设备形态
- 检测到新版本时会提示刷新，便于获取最新前端资源

## 适合的设备场景

- 在 NAS 管理机、家庭平板或手机上作为常用入口固定使用
- 将 Kaloscope 作为媒体控制台常驻在桌面环境
- 在移动端获得更接近原生应用的启动与切换体验

## 安装提示

- 桌面端通常可通过地址栏或浏览器菜单中的“安装应用”入口完成安装
- 移动端通常可通过浏览器菜单中的“添加到主屏幕”完成安装
- 若浏览器不支持 PWA 安装，仍可继续以普通网页方式访问
