# 快速开始

## 第一步：部署服务

参考[部署指南](./deployment)完成本地部署，推荐使用 [Docker Compose](./deployment#docker-compose) 方式同时部署 Kaloscope 与下载器。

## 第二步：访问页面

部署完成后，可通过浏览器访问`http://<宿主机IP>:8000`（若启用 TLS 则改为`https`）打开 Kaloscope 界面。首次访问时会跳转到管理员账号创建页面，注册完成后即可登录。

## 第三步：初始配置

登录成功后，建议按顺序完成以下配置：

1. [配置工作流](./workflows/templates)：导入模板，检查必要的全局变量，发布需要的索引器和资源入库工作流
2. [创建媒体库](./medialibs/)：选择电影、电视剧、小说或漫画类型，指定根目录并按需绑定刮削工作流；创建后会扫描已有文件
3. [添加下载器](./downloads/)：按需连接 aria2、qBittorrent、Transmission、OpenList 或 NAS 迅雷
4. [设置下载计划](./downloads/plans)：选择搜索工作流和下载器，配置完成后转移到刚创建的媒体库

只管理已有本地媒体时，完成媒体库配置即可，下载器和下载计划可以稍后添加。小说与漫画需先按[目录要求](./medialibs/reading#支持格式与目录)存放正文。

### 可选：启用 AI

1. 管理员在**设置 → 系统设置 → 模型提供商**中[添加连接](./ai/)，选择或手动填写模型 ID
2. 打开顶部导航栏的[助手](./ai/assistant)，选择支持工具调用的模型，即可开始对话
3. 需要在流程中处理文本或提取结构化数据时，加入 [AI 节点](./workflows/ai)

未配置 AI 不影响其余功能。助手生成的工作流需检查并保存为草稿，再手动发布。希望使用外部 AI 客户端时，在**个人设置 → 访问令牌**中创建令牌并按 [MCP 接入](./ai/mcp)配置，无需先启用内置助手。

## 第四步：完善媒体体验

- 希望按标题、年份和季集统一目录时，为媒体库设置[自动重命名模板](./medialibs/organization)，并确认 NFO 元数据完整
- 需要弹幕时，填写[弹幕服务器](./medialibs/danmaku)，然后在媒体条目菜单或播放器内确认匹配
- 浏览器无法直接播放视频时，配置[服务端转码](./medialibs/transcode)
- 阅读小说或漫画时，在阅读器中调整排版或翻页方式，并在个人设置中开启「最近阅读」
- 媒体库较大且不需要每次启动全量扫描时，可以关闭该开关；停机期间修改了文件后，记得[手动扫描](./medialibs/#扫描与实时监控)

需要按时间自动运行自定义工作流时，再配置[定时调度](./workflows/schedule)。
