# 快速开始

## 第一步：部署服务

参考[本地部署](./deployment)完成服务搭建。如果还没有现成的下载器，建议直接用 [Docker Compose](./deployment#docker-compose) 一起部署 Kaloscope 和下载器。

## 第二步：访问页面

服务启动后，在浏览器打开 `http://<宿主机IP>:8000`（如果开启了 TLS，协议改为 `https`）。首次访问会自动跳转到注册页，创建管理员账号后即可登录。

## 第三步：初始配置

登录后，按下面四步就能跑通完整流程：

1. [配置工作流](./workflows/templates)：导入现成模板，填好必要的全局变量，发布要用的索引器和入库刮削工作流
2. [创建媒体库](./medialibs/)：选择电影、电视剧、小说或漫画类型，指定根目录并按需绑定刮削工作流；建好后会自动扫描现有文件
3. [添加下载器](./downloads/)：按需接入 aria2、qBittorrent、Transmission、OpenList 或 NAS 迅雷
4. [设置下载计划](./downloads/plans)：选好搜索工作流和下载器，配置自动追更以及下载完成后的转移目标

如果你只打算管理本地现有的影视或书籍，建完媒体库就可以直接使用了，下载器和下载计划等有需要时再加就行。需要注意，小说与漫画的文件要先按[目录要求](./medialibs/reading#支持格式与目录)摆放。

### 可选：启用 AI

1. 让管理员前往 **设置 → 系统设置 → 模型提供商** [添加模型连接](./ai/)，获取或手动填写模型 ID
2. 点击顶部导航栏的[助手](./ai/assistant)，选一个支持工具调用的模型即可开始对话
3. 如果要在工作流里处理文本或提取结构化信息，可以在流程中加入 [AI 节点](./workflows/ai)

不配置 AI 完全不影响搜索、下载和媒体库等基础功能。需要留意的是，助手帮你生成的工作流会先保存为草稿，检查无误后再手动发布才会生效。如果你想在外部 AI 客户端里操作 Kaloscope，可以在 **个人设置 → 访问令牌** 创建令牌并参考 [MCP 接入](./ai/mcp)，这一步不需要先配内置模型。

## 第四步：常用进阶设置

- 想按标题、年份、季集自动归档文件？给媒体库填上[自动重命名模板](./medialibs/organization)，并确保 NFO 等元数据完整即可
- 看番剧想配弹幕？填好[弹幕服务器](./medialibs/danmaku)，在条目菜单或播放器里确认作品匹配就行
- 遇到浏览器放不出来的视频？去开启[服务端转码](./medialibs/transcode)
- 读小说或漫画时，可以在阅读器里调整排版和翻页习惯，并在个人设置里开启首页「最近阅读」
- 如果媒体库很大、不想每次重启都全盘扫一遍，可以关掉「启动时全量扫描」；不过在服务关闭期间增删过文件的话，记得之后[手动扫描](./medialibs/#扫描与实时监控)一次

如果有定时抓取或需要周期运行的自定义工作流，还可以去[定时调度](./workflows/schedule)里设置执行计划。
