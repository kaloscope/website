# 弹幕设置

弹幕功能分为媒体库的**服务器与匹配设置**，以及播放器中的**显示设置**。管理员可以在媒体库列表中为一个电影或剧集条目匹配弹幕，也可以在播放时手动确认单集。

## 弹幕服务器

在**媒体库管理**中新增或编辑媒体库，填写兼容弹弹play API 的「弹幕服务器」地址。可以使用自建服务，也可以填写 Kaloscope 提供的代理接口：

```text
https://danmaku.kaloscope.org
```

「弹幕缓存（小时）」默认为 `24`，有效范围为 `0`～`8760`。缓存有效时可直接复用；到期后会在下次加载时尝试重新获取。设为 `0` 表示下次加载就需要刷新，不表示永久缓存。

## 自动匹配

播放本地媒体时，播放器会优先使用已确认的匹配信息和缓存；没有匹配信息时，尝试根据文件信息自动匹配。

匹配不正确时，在播放器设置的「弹幕」页中使用「手动搜索」：输入作品名称，搜索后选择正确的作品和集数，再点击确认。搜索框下方会显示当前媒体路径，便于核对正在操作的文件。

确认电视剧单集后，系统还会尝试按集数补齐同一条目下其他分集的匹配信息。若不同季度的集数重复，应按季组织文件并选择对应季度的作品。

## 在媒体库中批量匹配

无需先播放视频，管理员可以直接在媒体库列表中操作：

1. 打开电影或剧集卡片的更多菜单，选择「弹幕」
2. 核对弹窗中的媒体路径，输入或修改作品名称并搜索
3. 选择正确的作品；对于分季作品，确认选择的是对应季度
4. 点击确认，将作品信息应用到该条目及其关联视频

电视剧按已识别的集数与服务端剧集列表对应。缺少集数或集数不匹配的文件，需先修正文件名或 NFO，再重新匹配；电影也支持从该入口匹配。

批量匹配的范围是**当前选中的媒体条目及其关联视频**，不会一次处理整个媒体库。更换作品匹配后，相关旧缓存会被清理，新的弹幕内容在播放时加载。未能匹配的集数不会因为选择了作品就自动获得正确弹幕。

## 显示与过滤

播放器的「弹幕」页可调整以下设置：

| 设置                           | 说明                                                            |
| ------------------------------ | --------------------------------------------------------------- |
| 弹幕开关                       | 开启或关闭显示                                                  |
| 屏蔽类型                       | 分别屏蔽滚动、顶部、底部或彩色弹幕                              |
| 显示区域、速度、不透明度、字号 | 调整弹幕在画面中的呈现方式                                      |
| 合并重复                       | 合并短时间内内容相同的弹幕，减少重复遮挡                        |
| 正则过滤                       | 屏蔽匹配正则表达式的内容，例如 `广告\|剧透`；无需填写两侧的 `/` |
| 本地缓存                       | 可删除当前视频的已缓存弹幕，后续加载时重新获取                  |

这些显示偏好保存在当前浏览器中；过滤和合并只影响播放时的显示，不改写原始弹幕缓存。
