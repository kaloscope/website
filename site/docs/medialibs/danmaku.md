# 弹幕设置

弹幕功能分为媒体库层面的**服务器与匹配设置**，以及播放器里的**显示设置**。管理员可以在媒体库列表里预先为整部电影或剧集匹配弹幕，看片时也能随时在播放器里手动微调单集。

## 弹幕服务器

在**媒体库管理**中新增或编辑媒体库，填好兼容弹弹play API 的「弹幕服务器」地址。可以用自建服务，也可以直接填写 Kaloscope 提供的代理地址：

```text
https://danmaku.kaloscope.org
```

「弹幕缓存（小时）」默认为 `24`，有效范围 `0`～`8760`。缓存没过期时会直接复用；到期后会在下次加载时重新拉取。注意填 `0` 表示下次加载就会刷新，不是永久缓存。

## 自动匹配

播放本地媒体时，播放器会优先读已经确认过的匹配信息和缓存；如果还没有记录，就会试着根据文件信息自动匹配。

遇到弹幕对不上的情况，打开播放器设置里的「弹幕」页使用「手动搜索」：输入作品名，挑中正确的作品和集数后点确认即可。搜索框下方会显示当前媒体路径，方便核对正在给哪一集配弹幕。

手动确认完电视剧的某一集后，系统还会尝试按集数把同一部剧下其他分集也补齐匹配。如果一部剧分了好几季且每季集数重复，建议按季建好目录，匹配时也要看准选择对应季度的作品。

## 在媒体库中批量匹配

不用先点开视频播放，管理员在媒体库列表里就能直接操作：

1. 打开电影或剧集卡片的更多菜单，选择「弹幕」
2. 核对弹窗里的媒体路径，输入或修改作品名称并搜索
3. 选出正确的作品；如果是分季作品，确认选中的是对应季度
4. 点击确认，把作品信息应用到该条目及关联视频

电视剧是按已识别的集数去对应服务端剧集列表的。缺少集数或集数对不上的文件，需要先修正文件名或 NFO 再重新匹配；电影同样可以从这个入口手动绑定弹幕。

注意这里只针对**当前选中的媒体条目及关联视频**生效，不会一口气修改整个媒体库。更换作品匹配后，旧的缓存会被清掉，新的弹幕会在播放时加载；没对上集数的单集，也不会因为选了作品就凭空获得正确弹幕。

## 显示与过滤

在播放器的「弹幕」页还可以按自己的习惯调整显示效果：

| 设置                           | 说明                                                            |
| ------------------------------ | --------------------------------------------------------------- |
| 弹幕开关                       | 开启或关闭弹幕显示                                              |
| 屏蔽类型                       | 分别屏蔽滚动、顶部、底部或彩色弹幕                              |
| 显示区域、速度、不透明度、字号 | 调整弹幕在画面里的呈现方式                                      |
| 合并重复                       | 合并短时间内内容相同的弹幕，减少重复遮挡                        |
| 正则过滤                       | 屏蔽匹配正则表达式的内容，例如 `广告\|剧透`；不用填写两侧的 `/` |
| 本地缓存                       | 删除当前视频的已缓存弹幕，后续加载时重新获取                    |

这些显示习惯保存在你当前使用的浏览器里；过滤和合并只影响播放时的画面呈现，不会改动原始弹幕缓存。
