# 小说与漫画

从 **v0.12.0** 开始，媒体库支持小说和漫画，可读取本地正文、封面和元数据，在浏览器中阅读并保存进度。创建方式与[影视库](./)相同，选择对应类型并填写服务端可访问的根目录。

## 支持格式与目录

| 类型 | 正文格式               | 目录要求                                                 |
| ---- | ---------------------- | -------------------------------------------------------- |
| 小说 | `TXT`、`EPUB`          | 根目录下一部小说一个文件夹，每个文件夹只放一个正文文件   |
| 漫画 | 图片目录、`CBZ`、`ZIP` | 根目录下一部漫画一个文件夹，可直接放正文，或按话再分一层 |

漫画图片支持 `JPG`、`JPEG`、`PNG`、`WebP` 和 `GIF`。同一个阅读单元应使用一组图片或一个压缩包；不要把多个正文压缩包或图片和压缩包混放在同一单元中。

### 小说示例

```text
Novels/
├── 示例小说 A/
│   ├── 正文.txt
│   └── 正文.opf
└── 示例小说 B/
    └── 正文.epub
```

TXT 会按内容识别章节，EPUB 会提取目录与支持的正文内容。EPUB 阅读器采用统一的阅读排版，不保证还原原文件中的全部样式和交互。

### 漫画示例

```text
Comics/
├── 示例单行本/
│   ├── ComicInfo.xml
│   ├── 001.jpg
│   └── 002.jpg
└── 示例连载/
    ├── ComicInfo.xml
    ├── 第 01 话/
    │   ├── 001.jpg
    │   └── 002.jpg
    └── 第 02 话/
        └── 第 02 话.cbz
```

连载目录可作为合集展示，在媒体详情或阅读器中切换各话。目录层级决定合集和阅读单元的归属，不支持无限层级嵌套。

## 扫描与索引

创建后会扫描已有内容；运行期间监控正文、目录和元数据变化。扫描与正文索引在后台处理，文件尚未稳定或索引未完成时，阅读入口可能暂时提示内容未就绪。

阅读异常时可由管理员在媒体库管理或侧栏执行手动扫描，发现文件变化、补齐缺失内容，并按需更新索引。未变化且仍有效的索引会复用；缺失阅读缓存会尝试恢复。扫描完成不代表所有刮削与整理工作已完成。

关闭「启动时全量扫描」不影响运行期间监控，停机期间改动文件后应手动补扫。源文件发生变化时，阅读进度会尽量恢复到可用位置；原位置失效时会提示并从可用章节起点继续。

## 元数据与封面

小说使用 **OPF**，漫画使用 **ComicInfo XML**，与影视库的 NFO 格式不同：

| 类型 | 本地来源                                                                                |
| ---- | --------------------------------------------------------------------------------------- |
| 小说 | 正文同目录的同名 `.opf`，或 `content.opf`、`metadata.opf`；EPUB 也可读取包内 OPF 和封面 |
| 漫画 | 正文目录中的 `ComicInfo.xml`；CBZ/ZIP 也可读取包内 ComicInfo 和封面信息                 |

外置元数据优先，缺失字段再从包内信息补齐。漫画章节还可继承合集中的作者、绘者、出版社和分类。标题、简介、作者、系列、卷号、话号、ISBN、出版日期等可在详情页展示，具体取决于文件中提供的信息。

为媒体库绑定「资源入库」工作流，使用对应的「小说」或「漫画」结束节点，可在首次入库且缺少本地元数据时自动刮削。管理员也可在条目菜单中选择「刮削元数据」，搜索并确认候选结果；结果保存为外置 OPF 或 ComicInfo，不会改写 EPUB/CBZ/ZIP 包内的原始内容。

## 在线阅读与进度

- 小说可切换章节，调整背景、字体、字号、行间距、段间距和左右边距
- 漫画支持滚动或翻页阅读，可调整图片缩放和翻页点击方向
- 详情页提供「阅读」或「继续阅读」入口，连载漫画可选择具体章节
- 阅读进度按账号保存；开启首页「最近阅读」后，可从首页返回上次阅读位置

在**个人设置**中可分别设置最近观看、最近阅读的展示，以及播放记录、阅读记录的保留时间。阅读设置和阅读进度是不同配置，重新扫描也不会主动清空账号的历史记录。

## 自动整理

小说与漫画也支持[自动重命名模板](./organization#小说与漫画示例)，但必须保持「作品目录/阅读单元名」两段结构。整理会处理外置元数据、相关封面和缓存引用，并保留条目标识及阅读进度；缺少必要字段或存在路径冲突时会跳过。
