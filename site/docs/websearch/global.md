# 全局搜索

不确定资源在哪个站点时，用全局搜索就不用逐个翻找了。输入一次关键词，系统会同时向所有符合条件的索引器发起搜索，结果按站点分标签页展示。

## 参与条件

并不是所有索引器都会出现在全局搜索里，它必须同时满足这三点：

- 处于启用状态，且工作流里包含搜索链路
- 在搜索链路的配置里开启了「参与全局搜索」选项
- 如果站点要求登录，当前用户已经完成认证

只要缺了一项，全局搜索时就会自动略过这个索引器，界面上也不会为它建标签页。

## 结果展示

每个标签页对应一个索引器，各自显示搜索结果和翻页状态。标签页标题上会标出站点名和匹配到的结果总数，点一下就能切换查看不同站点的结果。
