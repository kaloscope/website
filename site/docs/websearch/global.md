# 全局搜索

全局搜索适合在不确定资源来自哪个站点时使用。输入一个关键词后，系统会在所有符合条件的索引器中并行发起搜索，结果按索引器分标签页展示。

![websearch-global](/screenshots/websearch-global.png)

## 参与条件

索引器需同时满足以下条件，才会参与全局搜索：

- 已启用，且工作流中包含搜索链路
- 搜索链路配置中开启了「参与全局搜索」选项
- 如果站点要求登录，当前用户已完成认证

不满足任一条件的索引器会被自动跳过，不出现在标签页中。

## 结果展示

每个标签页对应一个索引器，显示该站点的独立搜索结果和分页状态。标签页标题会显示站点名称和结果总数，点击可切换查看不同站点的结果。
