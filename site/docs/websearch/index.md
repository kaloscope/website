# 资源搜索

Kaloscope 里的每个站点数据源都叫一个**索引器**，背后其实就是一条「网络搜索」工作流。一个索引器里最多可以搭四条链路，各自用不同的开始节点区分：

| 链路类型 | 起始节点        | 用途                                                   |
| -------- | --------------- | ------------------------------------------------------ |
| 搜索     | `search_start`  | 接收关键词，返回资源列表                               |
| 详情     | `details_start` | 通过资源 ID 进入详情页，展示视频、图片或文本等详情内容 |
| 认证     | `auth_start`    | 执行站点登录逻辑，保存认证状态                         |
| 首页     | `board_start`   | 抓取推荐或榜单，展示在首页                             |

并不是每个站都要把四条链路写全，目标站点支持什么功能就搭哪几条。所有索引器都在 **设置 → 工作流 → 流程定义** 里管理，可以随时单独启用或停用。

## 使用方式

- **单站搜索**：切到某个索引器页面，输入关键词就能搜，支持列表或网格两种视图
- **查看详情**：工作流里配了详情链路时，点一下搜索结果标题就能打开详情页
- **站点登录**：配了认证链路时，索引器页面右上角会出现「登录」按钮
- **收藏**：带有详情页的搜索结果可以加进收藏，之后在收藏页统一查看或清理
- **直接下载**：遇到带下载链接的搜索结果，管理员可以直接从页面发起下载任务
- **[全局搜索](./global)**：不确定资源在哪个站时，用全局搜索并行搜一遍所有已启用的索引器

## 在线预览

详情链路可以返回视频、音频、图片或文本，打开详情页时会自动匹配对应的播放器或阅读器。视频目前支持 `MP4`、`FLV`、`HLS` 和 `DASH`，实际能不能放出来还要看浏览器对编码的支持情况。

写详情工作流时，既可以在开始节点里设好默认的 `media_type` 和 `video_type`，也能在结束节点返回的数据里按单条资源动态指定。如果需要提供多清晰度或分集、章节目录，分别对应响应里的 `definitions` 和 `chapters` 字段，具体数据结构可以直接参考结束节点里的示例。

## 认证与权限

需要登录的站点，可以通过**认证链路**把登录态保存下来，之后搜资源、拉详情时工作流会自动带上这些登录状态。如果一个站要求登录但你还没完成认证，它的搜索结果会是空的，全局搜索时也会跳过它。
