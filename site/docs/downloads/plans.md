# 下载计划

对应主项目页面：`/downloads/plans`

下载计划用于自动追更和定时下载。系统会按预设规则周期性执行搜索工作流，将符合条件的资源自动提交到下载器，减少重复手动搜索。

## 计划列表

在**下载管理 → 下载计划**页面中，可查看所有计划的关键状态：

- 关联的工作流名称
- 搜索关键词
- 执行间隔
- 最近一次执行时间
- 已累计命中的资源数量
- 当前运行状态

## 筛选与管理

- 支持按工作流筛选计划
- 支持按关键词搜索计划
- 支持新增、编辑和删除计划
- 支持分页浏览大量自动化规则

## 配置内容

创建或编辑计划时，通常需要配置以下信息：

- 绑定执行用的搜索工作流
- 设置追更关键词
- 配置执行间隔或时间窗口
- 设置资源总数限制或其它过滤条件

## 执行逻辑

- 计划触发后自动执行对应工作流
- 搜索结果会按计划规则筛选
- 符合条件的资源自动提交到下载器
- 已处理过的资源可基于唯一标识去重，避免重复下载

## 适用场景

- 连载番剧或剧集的自动追更
- 固定关键词的周期性资源监控
- 通过规则将搜索、过滤、下载串成持续运行的自动流程
