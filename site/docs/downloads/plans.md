# 下载计划

下载计划用于自动追更。系统会按设定周期执行搜索工作流，把命中的资源自动送入下载器，减少重复手动搜索。

- 绑定一个可用于搜索的工作流
- 指定下载器、保存目录和搜索关键词
- 周期性执行搜索，并把结果自动加入下载器
- 记录最近执行时间、累计命中数量和运行状态

## 新增计划

在**下载计划**页面点击右上角「新增下载计划」，填写以下字段：

| 字段       | 必填 | 说明                                                               |
| ---------- | ---- | ------------------------------------------------------------------ |
| 工作流     | ✓    | 绑定一个「网络搜索」类别的工作流，用于定期执行搜索，创建后不可修改 |
| 关键词     |      | 传入工作流的搜索关键词；是否必填取决于搜索链路配置                 |
| 附加筛选   |      | 来自工作流搜索配置的额外筛选条件，如分辨率、字幕语言等             |
| 间隔       | ✓    | 计划触发的时间间隔，单位为小时                                     |
| 开始时间   |      | 计划的最早触发时间，留空则立即生效                                 |
| 结束时间   |      | 计划的最晚触发时间，留空则不限制结束                               |
| 单次上限   | ✓    | 每次执行最多提交的下载数量                                         |
| 总上限     |      | 计划累计提交的最大下载数量，达到后自动停止                         |
| 下载器     | ✓    | 将搜索结果提交到的目标下载器                                       |
| 保存到     | ✓    | 下载文件的保存路径                                                 |
| 完成后转移 |      | 下载完成后将文件转移到指定媒体库（见下方说明）                     |

## 完成后转移

如果为计划配置了**转移目标媒体库**，文件下载完成后会转移到媒体库根目录或替换后的相对路径下，并触发入库流程。

| 字段       | 必填 | 说明                                                           |
| ---------- | ---- | -------------------------------------------------------------- |
| 目标媒体库 | ✓    | 文件转移的目标媒体库                                           |
| 转移方式   | ✓    | 文件的迁移方式：`硬链接`、`软链接`、`移动`或`复制`             |
| 正则表达式 |      | 用于匹配原始下载文件名（相对于下载目录的保存路径）的正则表达式 |
| 替换字符串 |      | 替换结果，支持正则捕获组引用（如`\1`、`\2`）                   |

**文件名替换示例：**

| 正则表达式           | 替换字符串 | 原文件名                     | 结果文件名        |
| -------------------- | ---------- | ---------------------------- | ----------------- |
| `\[.*?\]\s*`         | （空）     | `[SubGroup] Show S01E01.mkv` | `Show S01E01.mkv` |
| `\s*\[.*?\](\.\w+)$` | `\1`       | `Show S01E01 [1080p].mkv`    | `Show S01E01.mkv` |
| `^(.+/)?`            | `Show/`    | `[SubGroup] Show/S01E01.mkv` | `Show/S01E01.mkv` |

::: tip 转移方式
转移方式推荐优先使用**硬链接**，在不占用额外空间的同时保留原始下载文件，便于做种。软链接适合跨卷场景，移动和复制会改变原始文件位置或占用双倍空间。
:::
