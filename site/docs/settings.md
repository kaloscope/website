# 系统设置

## 下载器

**设置 → 系统 → 下载器**

新增、编辑或删除下载器配置，每条配置包括类型、名称、连接地址和认证信息。点击「测试连接」验证连通性，可将某个下载器设为默认。

## 媒体库根目录

**设置 → 系统 → 媒体库**

添加媒体库根目录，需对应容器内的挂载路径，可为每个目录单独配置媒体库类型（电影 / 电视剧）。

## 网络代理

**设置 → 系统 → 网络**

为工作流 HTTP 请求节点设置全局代理，支持 HTTP / HTTPS / SOCKS5。

## 用户管理

**设置 → 系统 → 用户**（仅管理员可见）

创建、编辑或禁用用户，分配管理员或普通用户角色，可按媒体库和索引器单独控制访问权限。

## 工作流仓库

**设置 → 工作流**

管理工作流仓库及索引器绑定：添加本地仓库或从 GitHub 克隆、执行 `git pull` 拉取更新、创建并配置索引器，将工作流文件绑定到对应触发类型，启用或禁用单个索引器。

## 个人设置

**设置 → 个人**

- **语言**：简体中文 / 英文
- **主题**：浅色 / 深色
- **头像**：上传自定义头像
- **密码**：修改登录密码
