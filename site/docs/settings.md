# 系统设置

系统设置集中管理下载器、媒体库根目录、网络代理和用户权限等配置。

## 下载器

**设置 → 系统 → 下载器**

管理所有下载器连接：

- 新增、编辑或删除下载器配置
- 每条配置包括类型、名称、连接地址和认证信息
- 点击「测试连接」验证连通性
- 可将某个下载器设为默认，手动添加任务时优先使用

## 媒体库根目录

**设置 → 系统 → 媒体库**

管理媒体库的根目录配置：

- 添加新的媒体库根目录（需对应容器内的挂载路径）
- 可为每个目录单独配置媒体库类型（电影 / 电视剧）

## 网络代理

**设置 → 系统 → 网络**

为工作流中的 HTTP 请求节点设置代理：

- 支持 HTTP / HTTPS / SOCKS5 代理
- 代理配置全局生效，工作流的 HTTP 节点在发起请求时将自动使用

## 用户管理

**设置 → 系统 → 用户**

管理系统用户（仅管理员可见）：

- 创建、编辑或禁用用户
- 为用户分配角色：管理员或普通用户
- 按媒体库和索引器单独控制普通用户的访问权限

## 工作流仓库

**设置 → 工作流**

管理工作流仓库及索引器绑定：

- 添加本地仓库或从 GitHub 克隆社区模板
- 对已添加的仓库执行 `git pull` 拉取最新工作流
- 创建并配置索引器，将仓库内的工作流文件绑定到对应的触发类型
- 启用或禁用单个索引器

## 个人设置

**设置 → 个人**

当前登录用户的偏好配置：

- **语言**：简体中文 / 英文
- **主题**：浅色 / 深色
- **头像**：上传自定义头像
- **密码**：修改登录密码
