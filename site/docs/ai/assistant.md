# AI 助手

从 **v1.0.0** 起，Kaloscope 内置了 AI 助手。它能读取你当前打开的页面、应用数据和工作流日志，帮你查状态、排查问题、搭工作流，也能在经你确认后操作下载任务、定时调度和影视库入库。

## 开始对话

1. 由管理员先去[配置模型提供商](./)，保存并启用至少一个支持工具调用的模型
2. 点击顶部导航栏的「助手」，在面板里选好要用的模型
3. 先切到你要处理的页面（比如某个工作流、媒体详情、下载任务或计划页），再描述你的需求
4. 留意回复里的工具调用结果和变更预览，按提示确认后续操作

快捷键方面，按 `Ctrl / ⌘ + Enter` 发送消息，按 `Esc` 收起面板。助手面板支持自由拖动，收起后随时再点开。

助手会自动感知你当前打开的页面；切换页面后，再发送消息或重试时就会带上新页面的信息。提问时尽量写明目标名称、用途和限制条件，比起一句「处理全部资源」更容易得到准确且方便核对的结果。

## 可以处理的任务

| 场景             | 示例                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| 查询与排错       | 「帮我看下这个工作流最近一次为什么失败」「查一下还有哪些没下完的任务」     |
| 创建和修改工作流 | 「照着这个 JSON 样例搭一个搜索索引器」「给当前电影刮削流程加上年份筛选」   |
| 验证和试运行     | 「检查当前草稿有没有问题，再用这个关键词试运行一下，分析失败节点」         |
| 单次下载与追更   | 「搜一下这部剧，预览下载到影视库的路径」「建一个每 6 小时检查一次的计划」  |
| 管理已有任务     | 「暂停这个下载任务」「把刚才那个计划的结束时间延后」「为此工作流建定时任务」 |
| 影视库入库       | 「扫描一下这个电影库」「重新刮削这部电影」「修改该库的刮削流程和重命名模板」 |

目前影视库相关的扫描、重新刮削和入库配置操作仅支持**电影和电视剧**。小说与漫画的阅读、元数据和整理请参考[小说与漫画](../medialibs/reading)。

## 在画布上检查修改

在流程定义页，你可以直接让助手从零新建草稿；进入设计器后，也能让它修改当前画布上的流程。它能读取节点定义、校验模板、试探目标网站的 HTTP 接口，也能结合报错日志定位并修复节点问题。修改时，画布上的节点和连线变化会实时显示出来；如果所用模型支持推理展示，还能看到它的思考过程。

助手改完后，记得先检查一下节点、连线、字段和改动说明，再决定怎么处理：

- **保留并保存草稿**：把这次修改存为草稿；注意保存草稿不会立刻影响线上索引器或入库配置，仍需手动发布才会生效
- **撤回修改**：放弃助手这次对画布做的全部调整，回到修改前的状态

如果你在别的标签页或窗口同时改过同一个工作流，保存时可能会遇到版本冲突提示。这时重新加载一下草稿，再基于最新版本继续对话就行；如果不确定刚才那次保存到底成没成功，先查一下草稿状态再决定要不要重来。

### 试运行与发布

「校验」只会检查节点结构、字段和输出约定，不会真跑流程；而**「试运行」会真实执行已保存草稿**里的 HTTP、脚本、文件和 AI 节点，不仅会发出网络请求、写入文件，还可能产生模型调用费用。所以需要实测时再明确提出试运行，并仔细检查运行结果与日志。

试运行通过后，工作流依然不会自动发布；正式版本的切换仍需要管理员在编辑器里手动完成，发布后索引器、下载计划或媒体库才会用上新版。

## 操作前确认

涉及到创建下载、修改或删除计划、定时任务、控制下载进度，以及影视库扫描、重新刮削和配置修改时，助手不会直接动手，而是先为你展示目标、参数、影响范围和变更预览。点确认后才会真正提交；如果确认前改了设置或要求，系统会要求重新预览一次。

创建下载计划前，助手会先检查已有媒体和计划，提醒你有没有重复追更的风险，最终是否继续由你决定。如果是电视剧下载转移，建议特别核对一下[目录层级](../medialibs/#电视剧)和路径预览——用当前样例推算出来的路径，不一定和实际下载包里的文件结构完全一致。

操作提交后如果提示「已排队」，说明后台还在处理，并不代表下载或入库已经完成；状态不确定时可以先去对应页面查看，避免重复提交。让助手删除下载任务时默认会保留文件，只有当你明确要求删掉本地文件时，它才会连同文件一起删掉。

## 历史记录与权限

对话记录按账号分别保存，支持随时重新打开、重命名、单条删除或批量管理。对话太长时系统会自动压缩上下文，但你看到的原始聊天记录都会完整保留。遇到回复中断或报错时，刷新一下对话查看当前状态，再结合当前页面重试即可。

助手完全遵循当前登录账号的权限：普通用户只能查询自己获授权的资源，管理员操作依然需要管理员身份。发送给助手的问题与页面上下文会交给所选模型服务处理，涉及敏感数据时请按实际需要选择云端或本地模型。
