# AI 助手

内置助手结合当前页面、应用数据与工作流日志，帮助查询媒体和任务、搭建工作流，以及处理下载和影视入库。该功能从 **v1.0.0** 开始提供。

## 开始对话

1. 由管理员[配置模型提供商](./)，保存并启用至少一个支持工具调用的模型
2. 点击顶部导航栏的「助手」，在面板中选择模型
3. 打开要处理的工作流、媒体详情、下载任务或计划页面，描述需求
4. 查看回复中的工具调用、结果和变更预览，按提示完成后续操作

使用 `Ctrl / ⌘ + Enter` 发送消息，按 `Esc` 收起面板。面板可拖动，收起后可以再次打开。

助手会按当前页面获取相关上下文；切换页面后重试会使用新的页面信息。提问时写明目标名称、用途与限制，通常比一次要求处理全部资源更容易得到可核对的结果。

## 可以处理的任务

| 场景             | 示例                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| 查询与排错       | 「解释这个工作流最近一次失败的原因」「查找还没有完成的下载」               |
| 创建和修改工作流 | 「根据这个 JSON 样例搭建搜索索引器」「给当前电影刮削流程补充年份筛选」     |
| 验证和试运行     | 「校验当前草稿，并用这个关键词试运行，分析失败节点」                       |
| 单次下载与追更   | 「搜索这部剧，预览下载到影视库的路径」「创建每 6 小时检查一次的下载计划」  |
| 管理已有任务     | 「暂停这个下载任务」「修改这个计划的结束时间」「为此工作流创建定时任务」   |
| 影视库入库       | 「扫描这个电影库」「重新刮削这部电影」「调整该库的刮削工作流和重命名模板」 |

影视库扫描、重新刮削与入库配置目前面向**电影和电视剧**。小说、漫画的阅读、元数据和整理方式见[小说与漫画](../medialibs/reading)。

## 在画布上检查修改

在流程定义页可让助手创建草稿；进入设计器后，可让它修改当前流程。助手可以读取节点定义、校验模板、探测 HTTP 请求，以及结合日志修复问题。生成过程会实时展示画布修改；模型支持时也会展示推理内容。

修改完成后，请检查节点、连线、字段和变更说明，再选择：

- **保留并保存草稿**：保存这次修改，仍需手动发布才能用于实际索引器或入库配置
- **撤回修改**：撤回这次助手提出的画布变更

画布在其他页面或窗口被修改时，助手可能提示版本冲突。请重新加载草稿并基于当前版本提出需求；保存结果待确认时，先查询结果。

### 试运行与发布

校验只检查结构、字段和输出约定。**试运行会真实执行已保存草稿**中的 HTTP、脚本、文件和 AI 节点，可能发出网络请求、写入文件或产生模型调用费用；请明确提出试运行需求，并检查运行结果与日志。

试运行不会自动发布工作流；发布仍由管理员在编辑器中完成。发布后，索引器、下载计划或媒体库才会使用新的正式版本。

## 确认下载和媒体变更

涉及创建下载、修改或删除计划、定时任务、控制下载任务，以及影视库扫描、重新刮削和配置变更时，助手会先展示目标、参数、影响与预览。确认后才会提交对应操作；设置发生变化时需要重新预览。

创建下载计划前，助手可检查已有媒体和计划，提示潜在重复；是否继续由你决定。电视剧转移还应核对[目录层级](../medialibs/#电视剧)和路径预览；用样例推导的路径不能证明实际下载包中的文件完全一致。

操作结果显示「已排队」时，后台工作仍可能进行中；创建成功也不代表下载或入库已经完成。结果待确认时，先到对应页面检查状态，避免重复提交。删除下载任务时，只有明确要求删除文件，才会把文件删除纳入操作。

## 历史记录与权限

对话按账号保存，可重新打开、重命名或删除，也可批量管理。长对话会自动整理上下文，原始记录仍会保留。回复中断或失败时，可刷新对话查看状态，再根据当前页面重试。

助手沿用当前账号的权限，普通用户只能查询获授权的资源，管理员操作仍要求管理员身份。助手使用所选模型服务处理问题与所需上下文；请按实际需要选择云端或本地服务。
