# MCP 接入

Kaloscope 从 **v1.0.0** 开始内置 MCP 服务，可让外部 AI 客户端查询媒体、下载和工作流，编辑草稿，或在确认后管理任务。服务与 Web 界面共用地址，无需额外部署桥接进程，也无需先配置 Kaloscope 内置模型提供商。

## 创建访问令牌

1. 登录 Kaloscope，进入**设置 → 个人设置 → 访问令牌**
2. 点击「创建令牌」，填写名称、有效期和访问权限，默认是只读权限、90 天有效期
3. 创建后立即复制完整令牌；关闭弹窗后无法再次查看

| 访问权限 | 可用范围                                                                               |
| -------- | -------------------------------------------------------------------------------------- |
| 只读     | 查询当前账号有权访问的数据，读取工作流、日志和草稿，校验或预览变更                     |
| 读写     | 在账号权限范围内编辑草稿、执行搜索或 HTTP 探测、试运行，以及应用已确认的任务和媒体变更 |

读写令牌不会提升账号角色。草稿编辑、HTTP 探测、试运行、模型提供商信息和管理操作仍受管理员权限限制。

## 配置客户端

使用支持 **Streamable HTTP** 与 **Bearer 认证**的 MCP 客户端，添加服务器并填写：

| 配置项     | 值                                                             |
| ---------- | -------------------------------------------------------------- |
| 传输协议   | `Streamable HTTP`                                              |
| MCP 地址   | `http://127.0.0.1:8000/_api/mcp`，替换为客户端能访问的实例地址 |
| 认证请求头 | `Authorization: Bearer <token>`，将 `<token>` 替换为完整令牌   |

启用 TLS 时使用 `https`。外部客户端不在服务器本机运行时，应替换 `127.0.0.1`；若客户端提供 **Bearer Token** 输入框，只填写令牌本身。

令牌页面可直接复制当前实例的 MCP 地址和认证格式。连接后先尝试「列出我能访问的媒体库」，确认地址、认证和权限均正常。

## 可用能力

| 功能         | 说明                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 读取应用状态 | 查询媒体库与条目、下载任务与计划、工作流与日志、定时任务，以及管理员可见的模型连接信息         |
| 编写工作流   | 读取节点定义和编写参考，校验模板，预览修改，创建、保存及恢复工作流草稿版本                     |
| 调试工作流   | 探测 HTTP 请求，试运行已保存草稿，并检查节点错误与输出                                         |
| 管理下载     | 使用已发布索引器搜索，校验并创建单次下载或计划，修改和删除计划，暂停、恢复、重试或删除下载任务 |
| 管理定时任务 | 预览并确认创建、修改、暂停、恢复或删除工作流定时任务                                           |
| 影视库操作   | 预览并确认扫描、重新刮削，以及绑定工作流、语言和重命名模板变更                                 |

影视库操作目前仅面向电影和电视剧。返回的下载状态是 Kaloscope 已保存的状态，可能与下载器即时状态存在同步延迟。

## 变更流程

让客户端先读取目标和当前状态，再校验、展示差异及影响，确认后执行。草稿保存会检查版本，避免覆盖其他窗口的新修改；历史版本可恢复为新草稿。MCP 不提供发布或删除工作流、取消正在运行工作流的工具。

搜索、HTTP 探测、刮削候选搜索和试运行会真实访问外部服务或执行工作流。试运行还可能执行脚本、文件与 AI 节点；校验和预览通过不等于实际执行成功。

下载、计划、调度和媒体变更工具提供预览与确认步骤。结果待确认时，应查询同一次请求的结果或查看目标页面状态；不要直接创建一份新请求。任务已排队时，后续仍需查看后台处理结果。

## 管理令牌与排错

令牌列表显示到期时间和最近使用时间。删除令牌后，持有该令牌的客户端会失去访问权限；丢失完整令牌时，请删除旧令牌并创建新的。

- 无法连接：检查客户端是否支持 Streamable HTTP、实例地址和 `/_api/mcp` 路径是否正确
- 认证失败：检查完整令牌、到期时间，以及是否误把 `Bearer` 前缀填进了令牌输入框
- 只能读取：检查令牌是否为只读，以及账号是否具备对应操作权限
- 工具未提供所需操作：按上表核对当前能力；发布工作流等操作仍在 Kaloscope 界面完成
