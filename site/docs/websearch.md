# 资源搜索

## 索引器

索引器是搜索能力的基本单元，每个索引器绑定一组工作流，定义如何从指定站点搜索和获取资源。

| 工作流类型 | 说明 |
| --- | --- |
| 搜索工作流 | 接收关键词，返回资源列表 |
| 详情工作流 | 接收资源链接，返回磁力链接、海报、简介等 |
| 认证工作流 | 处理需要登录的站点，执行后保存会话 Cookie |
| 看板工作流 | 抓取站点首页的推荐或榜单内容 |

索引器在**设置 → 工作流**中管理，可单独启用或禁用。

## 关键词搜索

1. 在顶部搜索栏输入关键词，选择目标索引器
2. 点击搜索后执行对应索引器的搜索工作流
3. 点击某条结果，触发详情工作流获取磁力链接等信息
4. 在详情页可直接将资源发送到下载器

## 全局搜索

开启全局搜索后，系统同时向所有已启用的索引器发起请求，聚合展示结果。

## 站点登录

在索引器详情中触发认证工作流，完成后会话 Cookie 自动保存，后续请求自动携带。

## 注意事项

索引器工作流可包含任意 HTTP 请求和 Python 脚本，使用第三方工作流前请自行审查其行为。
