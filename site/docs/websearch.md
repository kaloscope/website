# 资源搜索

资源搜索模块通过工作流对接外部资源站，支持关键词搜索、详情预览和全局聚合搜索。

## 索引器

索引器是搜索能力的基本单元，每个索引器绑定一组工作流，定义如何从指定站点搜索和获取资源。

一个完整的索引器通常包含以下几类工作流：

| 工作流类型 | 说明 |
| --- | --- |
| 搜索工作流 | 接收关键词，返回资源列表（标题、链接、大小等） |
| 详情工作流 | 接收资源链接，返回详细信息（磁力链接、海报、简介等） |
| 认证工作流 | 处理需要登录的站点，执行后保存会话 Cookie |
| 看板工作流 | 抓取站点首页的推荐或榜单内容 |

索引器配置在**设置 → 工作流**中管理，每个索引器可以单独控制是否启用。

## 关键词搜索

1. 在顶部搜索栏输入关键词，选择目标索引器
2. 点击搜索后，系统执行对应索引器的搜索工作流
3. 结果列表展示资源名称、大小、做种数等信息
4. 点击某条结果，触发详情工作流获取磁力链接等下载信息
5. 在详情页可直接将资源发送到下载器

## 全局搜索

开启全局搜索后，系统会同时向所有已启用的索引器发起搜索请求，并将结果聚合展示。适合在多个来源之间快速比较资源。

## 站点登录

对于需要登录的站点，可在索引器详情中触发认证工作流。认证完成后，会话 Cookie 会被保存，后续请求自动携带。

## 注意事项

索引器工作流可以包含任意 HTTP 请求和 Python 脚本。使用社区或第三方工作流前，请自行审查其行为，确认安全性与合法性。
