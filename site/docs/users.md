# 用户管理

用户管理用于维护账号和权限范围。管理员可以控制每个普通用户能访问哪些媒体库和索引器。

- 创建普通用户账号并设置登录名与初始密码
- 查看用户角色、创建时间和最近活动时间
- 为普通用户分配权限
- 删除普通用户账号

## 权限边界

- 普通用户只能访问被授权的媒体库和索引器
- 管理员拥有完整权限，不需要单独分配

AI 助手和 MCP 接入同样遵守账号权限。普通用户不能通过对话或读写令牌获得管理员能力。

## 个人设置与访问令牌

每个用户可在**设置 → 个人设置**调整首页「最近观看」「最近阅读」的展示，以及搜索、播放和阅读记录的保留时间。

在**个人设置 → 访问令牌**可为 [MCP 客户端](./ai/mcp)创建独立令牌，选择有效期和只读或读写权限。完整令牌仅在创建时展示一次；令牌的访问范围同时受账号权限限制，删除后对应客户端不能继续使用。
