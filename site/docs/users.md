# 用户管理

**设置 → 系统 → 用户**（仅管理员可见）

Kaloscope 支持多用户协作使用，适合家庭媒体服务器或小型团队共享部署。管理员可统一维护账号、角色与访问范围，普通用户仅看到自己有权限访问的功能与资源。

## 账号管理

- 创建用户账号并设置登录名、密码与头像
- 编辑现有用户信息，或在不删除历史数据的前提下禁用账号
- 区分管理员与普通用户角色

## 权限控制

- 按媒体库分配访问权限，限制可浏览或可管理的资源范围
- 按索引器配置访问权限，控制可使用的搜索来源
- 管理员拥有完整系统设置权限，普通用户仅保留授权范围内的操作能力

## 使用场景

- 家庭成员共享同一套媒体服务，但各自访问不同媒体库
- 为儿童或访客创建受限账号，避免误操作系统配置
- 在保留统一工作流与下载器配置的前提下，实现多人独立使用
