# 用户管理

如果家里人或朋友也一起用你的 Kaloscope，可以在用户管理里给每个人单独建账号。管理员可以创建和删除普通用户、查看各账号的创建时间与最近活跃情况，还能细粒度控制每个账号能看到哪些媒体库、能用哪些索引器。

## 权限边界

- 普通用户只能看到和操作管理员明确授权给他的媒体库与索引器
- 管理员拥有全站权限，不需要额外分配

无论是网页里的 AI 助手，还是外部连进来的 MCP 客户端，都会严格遵守这套权限规则——普通用户没法靠对话话术或者拿一个读写令牌就越权执行管理员操作。

## 个人设置与访问令牌

每位用户都能在 **设置 → 个人设置** 里自己调整首页要不要显示「最近观看」「最近阅读」，以及搜索、播放和阅读记录的保留时长。

同样在 **个人设置 → 访问令牌** 下，还可以给 [MCP 客户端](./ai/mcp)生成专属令牌，自由选择有效期和只读或读写权限。完整令牌只在刚创建的那一刻显示一次，关掉弹窗就看不到了；删掉令牌后，拿着它的客户端也就不能再连进来了。
