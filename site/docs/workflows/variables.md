# 全局变量

全局变量用于集中维护工作流里的公共配置，适合存放接口地址、目录路径、请求头、令牌等需要复用的值。

- 支持按变量名进行筛选
- 变量名支持一键复制，方便在工作流字段中直接引用

## 新增变量

在**全局变量**页面点击右上角「新增变量」，填写以下字段：

| 字段     | 必填 | 说明                                                             |
| -------- | ---- | ---------------------------------------------------------------- |
| 名称     | ✓    | 全局变量的名称，保存后不可修改                                   |
| 值       | ✓    | 全局变量的值                                                     |
| 是否加密 |      | 点击变量值右侧图标即可切换，启用后变量值会加密存储并在列表中隐藏 |

## 使用方式

- 全局变量可以在工作流字段里通过 Jinja2 语法直接引用
- 把经常变动的配置从工作流里抽出来后，模板迁移和批量修改会更简单
