# 全局变量

如果好几个工作流都要用到同一个接口地址、根目录、请求头或令牌，不妨把它们抽成全局变量集中维护，不用在每个流程里重复填写。列表页支持按名字筛选，也支持一键复制变量名，直接贴进工作流字段里就能用。

## 新增变量

在**全局变量**页面点击右上角「新增变量」，按说明填写：

| 字段     | 必填 | 说明                                                           |
| -------- | ---- | -------------------------------------------------------------- |
| 名称     | ✓    | 全局变量的名称，保存后不可修改                                 |
| 值       | ✓    | 全局变量的值                                                   |
| 是否加密 |      | 点击变量值右侧图标即可切换；开启后会加密存储并在列表中隐藏明文 |

## 使用方式

- 在支持模板的节点字段里，直接通过 Jinja2 语法就能引用全局变量
- 把域名、令牌这类常变的配置抽出来后，以后修改配置或迁移模板会方便很多
