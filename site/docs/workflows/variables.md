# 全局变量

对应主项目页面：`/settings/workflows/variables`

全局变量用于集中维护工作流可复用的键值对，适合存放经常在多个节点中引用的参数、路径、接口地址或敏感配置。

## 列表与检索

- 支持按变量名搜索
- 支持按创建时间或更新时间排序
- 以分页方式浏览变量列表

## 变量内容

每条变量通常包含以下信息：

- 变量名
- 变量值
- 创建时间
- 更新时间

变量名支持直接复制，便于在工作流节点字段或模板中快速引用。

## 加密变量

- 支持将变量以加密方式保存
- 加密变量在列表中不会直接显示真实内容
- 适合保存令牌、密码、Cookie 或其它敏感配置

## 管理操作

- 新增变量
- 编辑已有变量
- 删除不再使用的变量

## 典型用途

- 为多个工作流统一提供基础 URL、请求头或目录路径
- 将敏感凭据从具体流程定义中抽离出来集中管理
- 降低工作流迁移、复用和维护时的重复修改成本
