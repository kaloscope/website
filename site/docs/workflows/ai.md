# AI 节点

AI 是工作流中的通用节点，可读取执行上下文，调用已配置的模型，将文本或经过校验的 JSON 写回上下文。适合内容整理、信息提取和分类等步骤，从 **v1.0.0** 开始提供。

使用前，由管理员在[模型提供商](../ai/)中保存并启用连接和模型。

## 配置字段

| 字段           | 说明                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 提供商与模型   | 选择已启用提供商中保存的模型                                          |
| 系统提示词     | 可选，支持 Jinja2 模板和上下文变量                                    |
| 提示词         | 必填，支持 Jinja2 模板；引用未定义变量会报错                          |
| 超时           | 每次请求的超时时间，默认 60 秒，可设为 1–300 秒                       |
| 失败重试次数   | 0–3 次，默认 0；仅重试临时请求故障，每次请求单独计算超时              |
| 最大输出 Token | 默认 0，使用模型默认值；部分模型的推理 Token 也计入此限制             |
| Temperature    | 0–2，留空使用模型默认值，需要模型支持                                 |
| 输出格式       | 「文本」或「结构化 JSON」                                             |
| JSON Schema    | JSON 模式下必填，使用不含引用的 Draft 2020-12 对象结构                |
| 原生结构约束   | JSON 模式的高级选项，要求模型服务原生按 Schema 约束生成，需要模型支持 |
| 输出变量       | 默认 `ai_result`；以字母开头，仅含字母、数字和下划线，最长 64 个字符  |

## 文本输出

例如，上游「设置变量」节点已经提供 `content`，可以填写以下提示词：

::: v-pre

```jinja
将以下内容整理为不超过三句话的中文简介：
{{ content }}
```

:::

成功后，默认通过以下字段读取结果：

| 字段              | 内容                                         |
| ----------------- | -------------------------------------------- |
| `ai_result.text`  | 模型返回的文本                               |
| `ai_result.json`  | 文本模式为 `null`，JSON 模式为校验通过的对象 |
| `ai_result.model` | 返回结果中的模型标识                         |
| `ai_result.usage` | 服务提供的 Token 用量信息，可能不完整        |

::: v-pre
下游模板可使用 `{{ ai_result.text }}`。修改输出变量名后，下游引用也需要同步修改。
:::

## 结构化 JSON

将输出格式切换为「结构化 JSON」，填写 Schema，例如：

```json
{
  "type": "object",
  "properties": {
    "result": { "type": "string" }
  },
  "required": ["result"],
  "additionalProperties": false
}
```

::: v-pre
提示模型把所需结果写入 `result`，下游即可通过 `{{ ai_result.json.result }}` 使用经过校验的值。
:::

关闭「原生结构约束」时，系统通过提示词约束输出；开启后还会向服务提交结构约束。**两种方式都会在本地校验结果**，不符合 Schema 的输出会使节点失败。

## 执行与排错

发布时会检查节点配置、模板语法、提供商与模型是否可用，但不会调用模型。只有实际执行或试运行才会发送请求。

请求成功且输出校验通过后，节点才会替换输出变量；失败时不会用不完整结果覆盖旧值。请求被拒绝时检查地址、模型和生成参数；输出被截断时增加输出 Token 限制或缩短内容；JSON 校验失败时检查 Schema 与提示词是否一致。

如果希望用自然语言搭建和调试整个工作流，可使用[内置助手](../ai/assistant)。
