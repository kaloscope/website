# 工作流

工作流是 Kaloscope 的核心能力，资源搜索、元数据刮削、定时任务等均通过工作流实现。

## 编辑器界面

- **节点面板**（左侧）：按类型分组展示所有可用节点，拖入画布即可使用
- **画布**（中央）：放置节点、连接句柄、调整布局
- **属性面板**（右侧）：选中节点后编辑字段参数
- **工具栏**：保存、运行、撤销、缩放等操作

## 节点类型

| 分组     | 节点         | 说明                                           |
| -------- | ------------ | ---------------------------------------------- |
| **入口** | 搜索入口     | 接收搜索关键词                                 |
|          | 详情入口     | 接收资源链接                                   |
|          | 认证入口     | 登录认证流程起点                               |
|          | 看板入口     | 首页推荐/榜单抓取起点                          |
|          | 下载计划入口 | 自动下载流程起点                               |
|          | 定时入口     | 由调度器触发                                   |
| **通用** | HTTP 请求    | 发起 HTTP 请求，支持自定义方法、请求头与请求体 |
|          | Python 脚本  | 执行内嵌 Python 代码，可操作上下文变量         |
|          | 文本处理     | 字符串拼接、替换、正则提取等                   |
| **控制** | 条件分支     | 根据表达式选择执行路径                         |
|          | 循环         | 对列表进行迭代                                 |
| **出口** | 搜索出口     | 输出搜索结果列表                               |
|          | 详情出口     | 输出标题、简介、磁力链等                       |
|          | 认证出口     | 完成登录并保存会话                             |
|          | 看板出口     | 输出首页推荐条目                               |
|          | 下载计划出口 | 将任务提交到下载队列                           |
|          | 定时出口     | 标记定时任务执行完成                           |
| **NFO**  | 电影 NFO     | 将元数据写入电影 NFO 文件                      |
|          | 剧集 NFO     | 将元数据写入剧集 NFO 文件                      |
|          | 电视剧 NFO   | 将元数据写入电视剧 NFO 文件                    |

## 工作流管理入口

- [流程模板](/docs/workflows/templates)：浏览仓库模板，引用或复制到本地工作流
- [全局变量](/docs/workflows/variables)：统一维护工作流可复用的键值变量
- [定时调度](/docs/workflows/schedule)：为工作流配置按日期、Cron 或间隔触发的任务

## 节点字段中的 Jinja2 模板

大多数节点字段支持 Jinja2 模板语法，可引用上下文变量或对数据进行转换处理。

::: v-pre

**基本引用**

```jinja
{{ title }}
{{ results[0].url }}
```

**过滤器**

```jinja
{{ content | xpath_first('//title/text()') }}
{{ ts | strftime('%Y-%m-%d') }}
{{ magnet | prefix('magnet:?xt=urn:btih:') }}
```

## 自定义 Jinja2 Filters

### 字符串处理

| 过滤器        | 示例                            | 说明                            |
| ------------- | ------------------------------- | ------------------------------- |
| `trim`        | `{{ v \| trim }}`               | 去除首尾空白，可传 `chars` 参数 |
| `ltrim`       | `{{ v \| ltrim }}`              | 去除左侧空白（或指定字符）      |
| `rtrim`       | `{{ v \| rtrim }}`              | 去除右侧空白（或指定字符）      |
| `json_escape` | `{{ v \| json_escape }}`        | JSON 转义                       |
| `prefix`      | `{{ v \| prefix('https://') }}` | 为非空值添加前缀                |
| `suffix`      | `{{ v \| suffix('.torrent') }}` | 为非空值添加后缀                |
| `b64encode`   | `{{ v \| b64encode }}`          | Base64 编码                     |
| `b64decode`   | `{{ v \| b64decode }}`          | Base64 解码                     |
| `s2t`         | `{{ v \| s2t }}`                | 简体转繁体                      |
| `t2s`         | `{{ v \| t2s }}`                | 繁体转简体                      |

### 数据提取

| 过滤器           | 示例                                      | 说明                                                  |
| ---------------- | ----------------------------------------- | ----------------------------------------------------- |
| `jsonpath_first` | `{{ obj \| jsonpath_first('$.name') }}`   | JSONPath 提取第一个匹配值                             |
| `jsonpath_all`   | `{{ obj \| jsonpath_all('$.items[*]') }}` | JSONPath 提取所有匹配值，返回列表                     |
| `jsonpath`       | `{{ obj \| jsonpath('$.items[*]') }}`     | 智能提取：单个返回值，多个返回列表，无匹配返回 `None` |
| `xpath_first`    | `{{ html \| xpath_first('//a/@href') }}`  | XPath 提取第一个匹配值                                |
| `xpath_all`      | `{{ html \| xpath_all('//a/@href') }}`    | XPath 提取所有匹配值，返回列表                        |
| `xpath`          | `{{ html \| xpath('//a/@href') }}`        | 智能 XPath 提取，逻辑同 `jsonpath`                    |
| `regex_first`    | `{{ text \| regex_first('(\d+)') }}`      | 正则提取第一个捕获组                                  |
| `regex_all`      | `{{ text \| regex_all('(\d+)') }}`        | 正则提取所有匹配，返回列表                            |
| `regex`          | `{{ text \| regex('(\d+)') }}`            | 智能正则提取，逻辑同 `jsonpath`                       |

`jsonpath`、`xpath`、`regex` 支持 `limit` 参数：

```jinja
{{ obj | jsonpath('$.items[*]', 'first') }}   {# 强制返回第一个值 #}
{{ obj | jsonpath('$.items[*]', 'all') }}     {# 强制返回列表 #}
{{ obj | jsonpath('$.items[*]', 3) }}         {# 返回前 3 个 #}
```

### 时间与路径

| 过滤器        | 示例                               | 说明                                                            |
| ------------- | ---------------------------------- | --------------------------------------------------------------- |
| `strftime`    | `{{ ts \| strftime('%Y-%m-%d') }}` | 时间戳/日期字符串/datetime 格式化，可传 `tz` 参数（小时偏移）   |
| `year`        | `{{ ts \| year }}`                 | 提取 4 位年份整数                                               |
| `duration`    | `{{ ms \| duration }}`             | 时长转可读格式（如 `01:23:45`），默认单位毫秒，可传 `unit` 参数 |
| `parent_path` | `{{ path \| parent_path }}`        | 获取父目录，可传 `levels` 参数（默认 1）                        |

:::

## 安全提示

工作流可包含任意代码或外部请求。导入第三方工作流前，请重点检查 HTTP 请求目标、Python 脚本行为、本地写入路径及外部数据上传风险。
