# 流程模板

不想从零搭建流程时，可以直接去流程模板里挑现成的工作流，按数据源、名称或分类筛一筛，再「引用」或「复制」到本地工作流列表里。

<img src="/screenshots/workflow-templates.png" alt="workflow-templates" width="1382" height="849">

## 添加仓库

模板来源是 GitHub 仓库。进入**流程模板**页面，点击右上角「编辑数据源」→「新增数据源」，填入仓库地址即可，支持两种写法：

- **仓库全称**：如 `kaloscope/workflows`
- **完整 URL**：如 `https://github.com/kaloscope/workflows`

添加后，系统会用 Git 拉取仓库内容，并在后台定时同步更新。列表里能看到每个仓库的名称、描述和上次同步时间。不用的来源随时可以删掉，已经导入到本地的工作流不会受影响。

::: tip 安全提示
第三方仓库里的模板可能包含任意请求和脚本，请只添加你信任的仓库。
:::

## 引用与复制

在列表里找到合适的模板后，点「引用」或「复制」即可导入：

- **引用模板**：和上游模板保持关联，适合想跟着后续更新一起升级的情况
- **复制模板**：生成完全独立的本地副本，方便你按自己的习惯随意修改

导入前，系统会自动起一个不和现有工作流冲突的默认名称。确认导入后，就能在本地工作流列表里看到它了。
