# 弹幕设置

Kaloscope 内置播放器支持弹幕显示，可在播放时按需开启、关闭和调整显示效果，兼顾番剧观看体验与移动端使用场景。

## 基础控制

- 开启或关闭弹幕显示
- 调整显示区域，避免遮挡字幕与画面主体
- 设置弹幕速度、不透明度与字号

## 屏蔽与过滤

- 按弹幕类型屏蔽滚动、顶部、底部或彩色弹幕
- 通过匹配规则过滤不需要显示的内容
- 在保留互动氛围的同时降低画面干扰

## 数据来源

- 支持配置兼容 dandanplay API 格式的弹幕服务器地址
- 可设置弹幕缓存时长，减少重复请求
- 提供手动搜索能力，便于在自动匹配不理想时重新选择弹幕来源

## 适用场景

- 观看番剧或综艺时保留社区互动体验
- 在电视、平板或手机横屏播放时按设备大小微调弹幕密度
- 结合本地媒体库播放，为归档资源补充在线弹幕内容
