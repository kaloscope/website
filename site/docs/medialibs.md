# 媒体库

媒体库负责管理本地视频文件、NFO 元数据和播放入口。

- 创建或启动后扫描已有文件，并持续监控根目录文件系统变动
- 一个媒体库对应一个根目录，适合按电影、剧集等类型拆分管理

![new-medialib](/screenshots/new-medialib.png)

## 创建媒体库

在**媒体库管理**页面点击「新增」，填写以下字段：

| 字段             | 必填 | 说明                                                         |
| ---------------- | ---- | ------------------------------------------------------------ |
| 类型             | ✓    | 媒体库类型，支持「电影」和「电视剧」，创建后不可修改         |
| 名称             | ✓    | 媒体库的显示名称                                             |
| 语言             |      | 偏好语言，用于刮削时指定元数据和字幕的语言                   |
| 目录             | ✓    | 媒体文件的根目录，需通过卷挂载到容器，创建后不可修改         |
| 弹幕服务器       |      | 弹幕接口地址，留空则不启用弹幕功能                           |
| 弹幕缓存（小时） |      | 弹幕数据的本地缓存时间，单位为小时，默认 24 小时             |
| 绑定的工作流     |      | 绑定「资源入库」类别的工作流触发器，用于自动或手动刮削元数据 |

## 元数据

Kaloscope 从 [NFO 文件](http://wikipedia.org/wiki/.nfo) 读取元数据，包括标题、简介、评分、年份、演员、导演、标签、海报等。NFO 文件需与媒体文件同名（仅扩展名不同），其内容为符合 [Kodi NFO 规范](https://kodi.wiki/view/NFO_files) 的 XML 文档。NFO 文件也可以通过资源入库工作流中的 [电影、电视剧或剧集结束节点](./workflows/index#工作流节点) 自动生成。

如果媒体库配置了关联工作流，还可以对单个媒体条目手动刮削：在媒体条目菜单点击「刮削元数据」，填写标题、年份、语言等条件后搜索候选结果，选中后确认即可将元数据写入 NFO 文件并更新媒体信息。

## 在线播放

点击媒体文件可在内置播放器中播放。播放器会优先直连播放浏览器支持的视频格式；启用服务端转码后，不兼容的视频可实时转为 HLS 播放。播放器支持弹幕、倍速、分集/分段切换和进度记录。

## 目录结构建议

Kaloscope 会根据文件在根目录下的层级自动识别媒体条目，建议按以下结构组织文件。

### 电影

```
Movies/
├── Film (1990).mp4
├── Film (1994).mp4
├── Film (2008)/
│   └── Film.mkv
└── Film (2010)/
    ├── Film-cd1.avi
    └── Film-cd2.avi
```

电影支持两种结构：直接放在根目录下的单文件，或放在以影片命名的子目录中（适合多分段或附带附件的情形）。

### 电视剧

```
Shows/
├── Series Name A (2010)/
│   ├── Series Name A S01E01.mkv
│   ├── Series Name A S01E02.mkv
│   └── Season 02/
│       ├── Series Name A S02E01.mkv
│       └── Series Name A S02E02.mkv
└── Series Name B (2018)/
    ├── Season 01/
    │   ├── Series Name B S01E01.mkv
    │   └── Series Name B S01E02.mkv
    └── Season 02/
        ├── Series Name B S02E01.mkv
        └── Series Name B S02E03.mkv
```

电视剧支持两种结构：分集直接放在剧集目录下（适合单季剧集），或按季分子目录存放。目录名或文件名中的年份和季数会被自动提取。
