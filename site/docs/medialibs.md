# 媒体库

媒体库模块负责本地媒体文件的组织、扫描、元数据管理与在线播放。

## 创建媒体库

在**媒体库**页面点击「新建媒体库」，填写以下信息：

- **名称**：媒体库的显示名称
- **类型**：电影或电视剧
- **根目录**：宿主机上的媒体文件根目录（需通过卷挂载到容器）

一个媒体库对应一个根目录。如果你有多个独立的媒体分类（如动漫、电影），建议分别创建。

## 文件扫描

媒体库支持两种方式识别新文件：

- **实时监控**：系统监控根目录下的文件系统变动，新增文件后自动触发扫描
- **手动扫描**：在媒体库详情页手动触发全量扫描

扫描时系统会遍历根目录下的所有媒体文件，识别支持的格式并尝试关联元数据。

## NFO 元数据解析

Kaloscope 支持从 [NFO 文件](https://kodi.wiki/view/NFO_files)中读取媒体元数据，包括：

- 标题、原始标题
- 简介、评分、年份
- 演员、导演、类型标签
- 海报、封面图片路径

NFO 文件需与媒体文件同名（仅扩展名不同），或按 Kodi 命名规范放置。也可以通过工作流自动生成 NFO 文件（参见[工作流 → NFO 节点](/docs/workflows#nfo-节点类型)）。

## 浏览媒体库

媒体库列表支持按类型、年份、标签等条件筛选，也可以通过关键词搜索。点击某个条目进入详情页，可查看完整元数据、剧集列表（电视剧）和关联的本地文件。

## 在线播放

点击媒体文件即可在内置播放器中播放，支持以下能力：

- **格式支持**：FLV、HLS、MP4
- **弹幕**：可叠加显示弹幕
- **移动端**：支持横屏播放
- **进度记录**：播放进度自动保存，下次打开可从上次位置继续播放

## 目录结构建议

为获得最佳扫描效果，建议按以下方式组织目录：

```
/animes/
├── 进击的巨人/
│   ├── tvshow.nfo
│   ├── Season 1/
│   │   ├── S01E01.mkv
│   │   ├── S01E01.nfo
│   │   └── ...
│   └── ...
└── ...

/movies/
├── 你的名字 (2016)/
│   ├── movie.nfo
│   ├── movie.mkv
│   └── ...
└── ...
```

媒体文件与同名 NFO 文件放在同一目录，便于扫描时自动关联。
