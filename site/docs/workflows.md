# 工作流

工作流是 Kaloscope 的核心能力，资源搜索、元数据刮削、定时任务等均通过工作流实现。

## 编辑器界面

工作流编辑器基于 [xyflow](https://xyflow.com/)，提供可视化画布：

- **节点面板**（左侧）：按类型分组展示所有可用节点，拖入画布即可使用
- **画布**（中央）：放置节点、连接句柄、调整布局
- **属性面板**（右侧）：选中节点后编辑其字段参数
- **工具栏**：保存、运行、撤销、缩放等操作

## 节点类型

| 分组 | 节点 | 说明 |
| --- | --- | --- |
| **入口** | 搜索入口 | 接收搜索关键词，作为搜索流程的起点 |
| | 详情入口 | 接收资源链接，作为详情抓取流程的起点 |
| | 认证入口 | 作为登录认证流程的起点 |
| | 看板入口 | 作为首页推荐/榜单抓取流程的起点 |
| | 下载计划入口 | 接收计划参数，作为自动下载流程的起点 |
| | 定时入口 | 由调度器触发，作为定时任务的起点 |
| **通用** | HTTP 请求 | 发起 HTTP 请求，支持 GET/POST 等方法、自定义请求头与请求体 |
| | Python 脚本 | 执行内嵌 Python 代码，可操作上下文变量 |
| | 文本处理 | 对字符串进行拼接、替换、正则提取等操作 |
| **控制** | 条件分支 | 根据表达式结果选择不同执行路径 |
| | 循环 | 对列表或数组进行迭代 |
| **出口** | 搜索出口 | 输出搜索结果列表 |
| | 详情出口 | 输出详情数据（标题、简介、磁力链等） |
| | 认证出口 | 完成登录并保存会话 |
| | 看板出口 | 输出首页推荐条目 |
| | 下载计划出口 | 将任务提交到下载队列 |
| | 定时出口 | 标记定时任务执行完成 |
| **NFO** | 电影 NFO | 将元数据写入电影 NFO 文件 |
| | 剧集 NFO | 将元数据写入剧集 NFO 文件 |
| | 电视剧 NFO | 将元数据写入电视剧 NFO 文件 |

## 节点字段中的 Jinja2 模板

大多数节点的字段值均支持 Jinja2 模板语法，可以引用上下文变量或对数据进行转换处理。

::: v-pre

**基本引用**

```jinja
{{ title }}
{{ results[0].url }}
```

**过滤器**

```jinja
{{ content | xpath_first('//title/text()') }}
{{ ts | strftime('%Y-%m-%d') }}
{{ magnet | prefix('magnet:?xt=urn:btih:') }}
```

## 自定义 Jinja2 Filters

Kaloscope 在标准 Jinja2 过滤器基础上注册了以下自定义过滤器：

### 字符串处理

| 过滤器 | 示例 | 说明 |
| --- | --- | --- |
| `trim` | `{{ v \| trim }}` | 去除首尾空白，可传 `chars` 参数指定去除的字符 |
| `ltrim` | `{{ v \| ltrim }}` | 去除左侧空白（或指定字符） |
| `rtrim` | `{{ v \| rtrim }}` | 去除右侧空白（或指定字符） |
| `json_escape` | `{{ v \| json_escape }}` | 对字符串进行 JSON 转义 |
| `prefix` | `{{ v \| prefix('https://') }}` | 为非空值添加前缀，值或前缀为空时返回空字符串 |
| `suffix` | `{{ v \| suffix('.torrent') }}` | 为非空值添加后缀，值或后缀为空时返回空字符串 |
| `b64encode` | `{{ v \| b64encode }}` | Base64 编码 |
| `b64decode` | `{{ v \| b64decode }}` | Base64 解码 |
| `s2t` | `{{ v \| s2t }}` | 简体中文转繁体中文 |
| `t2s` | `{{ v \| t2s }}` | 繁体中文转简体中文 |

### 数据提取

| 过滤器 | 示例 | 说明 |
| --- | --- | --- |
| `jsonpath_first` | `{{ obj \| jsonpath_first('$.name') }}` | JSONPath 提取第一个匹配值 |
| `jsonpath_all` | `{{ obj \| jsonpath_all('$.items[*]') }}` | JSONPath 提取所有匹配值，返回列表 |
| `jsonpath` | `{{ obj \| jsonpath('$.items[*]') }}` | 智能 JSONPath 提取：单个结果返回值，多个返回列表，无匹配返回 `None` |
| `xpath_first` | `{{ html \| xpath_first('//a/@href') }}` | XPath 提取 HTML 中第一个匹配值 |
| `xpath_all` | `{{ html \| xpath_all('//a/@href') }}` | XPath 提取 HTML 中所有匹配值，返回列表 |
| `xpath` | `{{ html \| xpath('//a/@href') }}` | 智能 XPath 提取，逻辑同 `jsonpath` |
| `regex_first` | `{{ text \| regex_first('(\d+)') }}` | 正则表达式提取第一个捕获组 |
| `regex_all` | `{{ text \| regex_all('(\d+)') }}` | 正则表达式提取所有匹配，返回列表 |
| `regex` | `{{ text \| regex('(\d+)') }}` | 智能正则提取，逻辑同 `jsonpath` |

`jsonpath`、`xpath`、`regex` 三个智能过滤器均支持 `limit` 参数：

```jinja
{{ obj | jsonpath('$.items[*]', 'first') }}   {# 强制返回第一个值 #}
{{ obj | jsonpath('$.items[*]', 'all') }}     {# 强制返回列表 #}
{{ obj | jsonpath('$.items[*]', 3) }}         {# 返回前 3 个，以列表返回 #}
```

### 时间与路径

| 过滤器 | 示例 | 说明 |
| --- | --- | --- |
| `strftime` | `{{ ts \| strftime('%Y-%m-%d') }}` | 将时间戳、日期字符串或 datetime 对象格式化为字符串，可传 `tz` 参数指定时区偏移（小时） |
| `year` | `{{ ts \| year }}` | 从时间戳或日期字符串中提取 4 位年份整数 |
| `duration` | `{{ ms \| duration }}` | 将时长转为可读格式（如 `01:23:45`），默认单位为毫秒，可传 `unit` 参数：`milliseconds`、`seconds`、`minutes` |
| `parent_path` | `{{ path \| parent_path }}` | 获取路径的父目录，可传 `levels` 参数指定向上层数（默认 1） |

:::

## 工作流仓库

工作流通过**仓库**统一管理。仓库对应一个 Git 仓库目录，存储在 `/workspace/repositories`。

- 可以手动创建本地仓库，或从 GitHub 克隆社区模板
- 仓库内的每个 JSON 文件对应一个工作流定义
- 通过**设置 → 工作流**页面管理仓库列表、拉取更新

## 定时触发

带有**定时入口**节点的工作流可以配置 Cron 表达式，由后端调度器按时触发。适合定期抓取更新、刷新榜单等场景。

## 典型应用场景

- 从资源站搜索番剧并解析详情页
- 根据关键词定时检索新资源并自动下发到下载器
- 调用脚本节点处理页面内容或自定义过滤规则
- 将媒体文件入库前执行一组清洗、匹配和命名步骤

## 一个常见流程示例

下面是一条更贴近项目定位的典型链路：

1. `schedule` 或 `search` 节点作为入口。
2. `http` 节点请求资源站接口或网页。
3. `text` 或 `script` 节点解析返回内容、提取结果。
4. `condition` 节点过滤标题、分辨率、字幕等条件。
5. `loop` 节点遍历候选资源。
6. `details` 或 `ingest` 节点进入详情和入库流程。
7. `end` 节点将结果交给搜索展示、计划任务或下载模块。

## 安全提示

工作流可能包含任意代码或外部请求。导入第三方工作流前，应重点检查：

- 请求目标与认证信息用途
- Python 脚本节点的执行行为
- 是否会写入本地敏感目录
- 是否会将数据上传到外部服务
